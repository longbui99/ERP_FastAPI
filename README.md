# FastAPI Sample Project

A simple FastAPI project demonstrating basic REST API functionality.

## Features

- Basic CRUD operations for items
- Request body validation using Pydantic
- Error handling
- API documentation (auto-generated by FastAPI)

## Installation

1. Create a virtual environment (recommended):
```bash
python3 -m venv venv
source venv/bin/activate  # On Windows, use: venv\Scripts\activate
```

2. Install dependencies:
```bash
pip3 install -r requirements.txt
```

## Running the Application

Start the server with:
```bash
uvicorn main:app --reload
```

The server will start at `http://localhost:8000`

## API Documentation

Once the server is running, you can access:
- Interactive API documentation (Swagger UI) at `http://localhost:8000/docs`
- Alternative API documentation (ReDoc) at `http://localhost:8000/redoc`

## Available Endpoints

- `GET /`: Welcome message
- `GET /items`: List all items
- `POST /items`: Create a new item
- `GET /items/{item_id}`: Get a specific item by ID

## Example Usage

Create a new item:
```bash
curl -X POST "http://localhost:8000/items" \
     -H "Content-Type: application/json" \
     -d '{"name": "Sample Item", "description": "A test item", "price": 29.99, "is_available": true}'
```
